## 1. 產品目標

校內職員系統，用來看學生手機櫃**最後使用**與**歷史開門紀錄**。

| 檢視 | 顯示 |
|------|------|
| 學生 | 班別（所屬部門）、學號（用戶編號）、姓名（用戶名，空白則不顯示）、最後開門日期時間、最後箱門。無最後時間則該欄顯示「空置」。 |
| 箱門 | A–G 各櫃。每格：櫃名（例如「A 櫃」）、格號（例如 `003`）、學生姓名（空白則不寫）、最後使用日期時間、按鈕「以往記錄」。該格從未有紀錄 → 整格狀態「空置」。 |
| 歷史 | 該學生或該箱門全部開門列（Excel 各欄入庫後可查）。 |

**最後使用判定：** 不論 `开箱类型` 是什麼（存入／取出／其他），該次開門都更新「該生最後箱門」與「該格最後使用者」。取出後仍顯示該學生，不改為空置。

資料來源：內聯網 `http://10.127.7.200:17789/#/Logs/OpenLog`。由**用戶的電腦或手機**（已入校網）取數，再交給本系統寫入 PostgreSQL。

## 2. 已鎖定的架構

```
用戶電腦／手機（學校 Wi‑Fi 或有線）
        │
        ├─ 探測／開啟  http://10.127.7.200:17789
        │     不在內聯網 → 中英提示，仍可查已存紀錄
        │
        ├─ 主要：在 OpenLog 按日期範圍導出 Excel → 上傳到本系統
        └─ 若瀏覽器允許（無 CORS／混合內容阻擋）：一鍵從本頁呼叫導出 API
                 │
                 ▼
本系統 app + PostgreSQL（校內 Docker，職員用手機／電腦開）
        解析 Excel、去重、重算最後狀態
```

**GitHub** 只放原始碼。執行仍是校內一台機 `docker compose up`（網頁 + PostgreSQL），讓職員用**電腦或手機瀏覽器**開啟 `http://<內網IP>:3000`。

這台 Docker 主機**不需要**自己連去爬 `:17789`。取數發生在用戶裝置。因此本系統用 **HTTP**（不要 HTTPS），否則手機／電腦瀏覽器會把對 `http://10.127.7.200` 的請求當混合內容擋掉。

| 服務 | 角色 | 端口 |
|------|------|------|
| `app` | 網頁、登入、設定、查詢、接收用戶上傳／瀏覽器取回的 Excel | 校內 `:3000`（HTTP） |
| `db` | PostgreSQL 16 | 僅 Docker 內網 |

**不做：** 伺服器 Playwright 常駐爬頁；不把同步放到 GitHub Actions／雲端。

## 4. Excel 欄位對應

導出檔表頭（簡體，必須對得上）：

| Excel 欄 | 系統用途 |
|----------|----------|
| 用户名 | 學生姓名；空則畫面不顯示姓名 |
| 用户编号 | 學號 |
| 所属部门 | 班別 |
| 箱门 | 例如 `B-032号箱` → 櫃 `B`、格 `032` |
| 开箱类型 | 原文入庫；不影響「最後 locker」 |
| 验证方式 | 入庫；歷史頁可顯示 |
| 管理员 | 入庫 |
| 备注 | 入庫 |
| 开箱时间 | 最後使用時間；解析後存 `timestamptz` |

箱門解析：`^([A-Ga-g])-(\d{1,3})\s*号箱$`  
正規化：`cabinet = 大寫字母`，`door_no = 三位補零`（`32` → `032`），`locker_code = B-032`。

只處理櫃 **A–G**。其他櫃號列仍入 `open_events` 但箱門總覽不建頁。

去重指紋：`开箱时间` + `用户编号` + 正規化 `locker_code` + `开箱类型`。重複匯入不插第二筆。

## 5. 同步規則（用戶裝置取數）

同步按鈕在**用戶的電腦或手機瀏覽器**上執行，不在雲端、不在 Docker 背景爬蟲。

### 5.1 不在內聯網

瀏覽器探測 `http://10.127.7.200:17789`（短 timeout）。失敗則：

- zh-HK：`未能連接校內手機櫃系統（10.127.7.200）。請用已連接學校網絡的電腦或手機再同步。已保存的歷史紀錄仍可查閱。`
- en：`Cannot reach the school locker system (10.127.7.200). Use a computer or phone on the school network and try again. Saved history remains available.`

已存 PostgreSQL 紀錄仍可查。

### 5.2 主路徑（電腦與手機都要用）：導出 Excel 後上傳

1. 畫面顯示今次應填的日期範圍（首次 `2025-09-01` → 今天；其後由上次成功日重疊 1 日起）。
2. 按鈕「開啟開門日誌」→ 新分頁 `http://10.127.7.200:17789/#/Logs/OpenLog`（用戶在該頁已登入即可，本系統讀不到該頁的 sessionStorage）。
3. 用戶在原廠頁填日期、按「導出 Excel」。
4. 回到本系統，選擇檔案上傳。伺服器解析九欄、去重、重算最後狀態。

此路徑不依賴 CORS、不依賴我們複製 session。手機 Safari／Chrome 都做得到。

### 5.3 一鍵同步（能才開）

若本頁用 HTTP，且原廠 API 允許跨來源讀取，瀏覽器可用設定頁的 `__tea_session_id_586864` JSON 嘗試直接下載。失敗則自動退回 5.2，並說明原因（CORS／未登入／session 失效）。

設定頁仍可選填 session JSON，**不是手機同步的必要步驟**。

### 5.4 日期與去重

- 首次：`from = 2025-09-01`，`to = 今天（香港）`。
- 其後：`from = last_success_open_date`（重疊 1 日），`to = 今天`。
- 不清舊 log。指紋：`开箱时间` + `用户编号` + `locker_code` + `开箱类型`。

### 5.5 09:45／18:30

伺服器**不能**在沒有用戶裝置的情況下連內聯網。改為：

- 首頁人手「立即同步／上傳 Excel」（主功能）。
- 若該時段有已登入且探測到內聯網的分頁開著，瀏覽器可自動提示「請同步」。
- 不保證無人開網頁時仍自動入庫。

（若你堅持無人值守自動入庫，必須另放一台 24 小時校內電腦跑爬蟲。你這次說明是用戶裝置取數，故不採用。）

## 6. 畫面（尚未實作，僅規格）

右上：`繁體中文（香港）` / `English`。日期 `yyyy-mm-dd`。

### 6.1 登入

`admin` / `000000`。錯誤不區分帳號或密碼。

### 6.2 設定頁（你要求新增）

已登入才能開。

| 欄位 | 說明 |
|------|------|
| 內聯網網址 | 預設 `http://10.127.7.200:17789` |
| Session Storage（可選） | 僅供一鍵 fetch；手機上傳 Excel **不必**填 |
| 首次匯入日起 | 預設 `2025-09-01` |
| 每櫃格數上限 | 預設 `120` |
| 同步說明 | 顯示建議日期範圍；09:45／18:30 為提醒而非伺服器代抓 |

### 6.3 首頁 — 學生

表格：班別、學號、姓名（無則留空不寫「空」）、最後箱門、最後使用日期時間（無則「空置」）。搜尋班別／學號／姓名。每列有「以往記錄」。

只列出 **log 裡出現過的學號**。無名冊、不列從未開門的學生。

### 6.4 首頁 — 箱門

分櫃 **A 櫃 … G 櫃**。每櫃以**密集格線**顯示 `001`–`120`（各櫃實際格數不同，上限 120；多出來的格若無紀錄即「空置」）。

每格：

- 格號 `003`（三位）
- 學生姓名（無則不寫該行）
- 最後使用時間（`yyyy-mm-dd HH:mm:ss`）
- 按鈕：以往記錄

該格完全無事件：**空置**（不顯示姓名與時間）。可提供「隱藏空置」開關，避免 120 格太長；預設顯示全部以便對實物。

有事件：即使最後一次是取出，仍顯示該學生 + 最後時間。

### 6.5 以往記錄頁

來自學生列或箱門按鈕。表列：开箱时间、用户名、用户编号、所属部门、箱门、开箱类型、验证方式、管理员、备注。可再篩日期。分頁。

### 6.6 頁首同步列（電腦與手機同一流程）

- 內聯網狀態（本機瀏覽器探測）
- 建議搜尋日期範圍（`yyyy-mm-dd`–`yyyy-mm-dd`）
- 「開啟開門日誌」（新分頁）
- 「上傳 Excel」
- 「一鍵同步」（探測失敗或 CORS 失敗則停用並提示改上傳）
- 最後成功同步時間

### 6.7 第一期不做

Google 登入、校外存取、遙距開箱、學生自助、推播、改原廠 `:17789` 系統。

### 7.2 `app_settings`（單列）

### 7.3 `sync_state`（單列）

`last_attempt_at`，`last_success_at`，`last_success_open_date`，`last_error`，`last_row_count`。

### 7.4 `open_events`

`opened_at`，`student_name`，`student_no`，`class_code`，`cabinet`，`door_no`，`locker_code`，`open_type`，`verify_method`，`admin_name`，`remark`，`source`（`browser_upload` / `browser_fetch`），`row_fingerprint` unique，`raw_json`。

### 7.5 `student_current` / `locker_current`

由事件重算。箱門總覽產生 A–G × `001`…`120`；無對應事件則畫面「空置」。超過 120 的格號若出現在 Excel，仍入 `open_events` 並顯示（不丟資料）。

## 8. 安全

- 本系統密碼 bcrypt；內聯網 session JSON／token 只存設定表，不進版控、不寫 info log。對話裡的 UUID **不會**寫進倉庫。
- Cookie session：`httpOnly`、`sameSite=lax`；校內 HTTP 不強制 `secure`。
- 同步與改設定必須已登入。
- 上傳限 `.xlsx`／`.xls`、20 MB。
- 不提供刪改單筆開門事實；不去清舊 log。
- PostgreSQL 不映射到校外。防火牆僅校內開 `:3000`。
