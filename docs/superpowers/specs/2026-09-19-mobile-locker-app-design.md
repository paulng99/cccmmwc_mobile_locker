# 手機櫃資訊應用 — 設計規格（已按你的回覆修訂）

> 日期：2026-09-19  
> 狀態：**規格已鎖定；按「更新」= 用戶瀏覽器自動向內聯網取 Excel**  
> 範圍：校內專用；今期不寫公開雲、不做 Google 登入  
> 語言：`zh-HK` + `en` 對照；日期 `yyyy-mm-dd`；時間 `HH:mm:ss`；時區 `Asia/Hong_Kong`

你說「開始寫」之後才實作網頁。

**取數位置：** 用戶按「更新」→ **該用戶瀏覽器**自動向 `http://10.127.7.200:17789` 取 Excel（帶記住的日期範圍）→ 本系統入庫。不用人手在原廠頁按導出。不在校網則提示。

---

## 1. 產品目標

校內職員系統，用來看學生手機櫃**最後使用**與**歷史開門紀錄**。

| 檢視 | 顯示 |
|------|------|
| 學生 | 班別（所屬部門）、學號（用戶編號）、姓名（用戶名，空白則不顯示）、最後開門日期時間、最後箱門。無最後時間則該欄顯示「空置」。 |
| 箱門 | A–G 各櫃。每格：櫃名（例如「A 櫃」）、格號（例如 `003`）、學生姓名（空白則不寫）、最後使用日期時間、按鈕「以往記錄」。該格從未有紀錄 → 整格狀態「空置」。 |
| 歷史 | 該學生或該箱門全部開門列（Excel 各欄入庫後可查）。 |

**最後使用判定：** 不論 `开箱类型` 是什麼（存入／取出／其他），該次開門都更新「該生最後箱門」與「該格最後使用者」。取出後仍顯示該學生，不改為空置。

資料來源：內聯網 `http://10.127.7.200:17789/#/Logs/OpenLog`。由**用戶的電腦或手機**（已入校網）取數，再交給本系統寫入 PostgreSQL。

## 2. 已鎖定的架構

```
用戶按「更新」（電腦或手機瀏覽器，須已入校網）
        │
        ▼
探測 http://10.127.7.200:17789
        │
        ├─ 不通 → 中英提示，仍可查已存紀錄
        │
        └─ 通 → 瀏覽器 fetch 開門日誌導出 API
                  日期：上次成功日（首次 2025-09-01）～今天
                  認證：設定頁 session JSON 及／或 credentials: include
                  取得 .xlsx 位元組
                  POST 到本系統 /api/import
                  解析、去重、重算學生／箱門最後狀態
```

本系統必須用 **HTTP**（`http://<內網IP>:3000`）。若用 HTTPS，瀏覽器會擋住對 `http://10.127.7.200` 的請求（混合內容），手機一樣。

**瀏覽器跨來源限制（CORS）：** 本頁來源是 `:3000`，Excel 在 `:17789`。若原廠 API **沒有** `Access-Control-Allow-Origin`，瀏覽器會禁止 JS 讀取檔案（這是所有手機／電腦瀏覽器的規則，不是我們能關的）。

若實測 CORS 擋住：同一顆「更新」按鈕改走 **同源轉發**——瀏覽器只請求本系統 `/api/intranet-export`，由校內 Docker **在這次點擊裡**轉向 `:17789` 取檔。仍是用戶按下才取，不是背景爬蟲；但連線 `:17789` 的是 Docker 主機，因此 Docker 也要在校網。這是備援，不是你要的「瀏覽器直連」主路徑。

**GitHub** 只放原始碼。執行仍是校內一台機 `docker compose up`（網頁 + PostgreSQL），讓職員用**電腦或手機瀏覽器**開啟 `http://<內網IP>:3000`。

這台 Docker 主機在「瀏覽器直連成功」時不必自己爬 `:17789`。直連失敗才需要它也在校網做轉發。

| 服務 | 角色 | 端口 |
|------|------|------|
| `app` | 網頁、登入、設定、接收瀏覽器取回的 Excel；CORS 失敗時可轉發導出 | 校內 `:3000`（HTTP） |
| `db` | PostgreSQL 16 | 僅 Docker 內網 |

**不做：** 伺服器 Playwright 常駐爬頁；不把同步放到 GitHub Actions／雲端。

## 4. Excel 欄位對應

導出檔表頭（簡體，必須對得上）：

| Excel 欄 | 系統用途 |
|----------|----------|
| 用户名 | 學生姓名；空則畫面不顯示姓名 |
| 用户编号 | 學號 |
| 所属部门 | 班別 |
| 箱门 | 例如 `B-032号箱` → 櫃 `B`、格 `032` |
| 开箱类型 | 原文入庫；不影響「最後 locker」 |
| 验证方式 | 入庫；歷史頁可顯示 |
| 管理员 | 入庫 |
| 备注 | 入庫 |
| 开箱时间 | 最後使用時間；解析後存 `timestamptz` |

箱門解析：`^([A-Ga-g])-(\d{1,3})\s*号箱$`  
正規化：`cabinet = 大寫字母`，`door_no = 三位補零`（`32` → `032`），`locker_code = B-032`。

只處理櫃 **A–G**。其他櫃號列仍入 `open_events` 但箱門總覽不建頁。

去重指紋：`开箱时间` + `用户编号` + 正規化 `locker_code` + `开箱类型`。重複匯入不插第二筆。

## 5. 同步規則（按「更新」= 瀏覽器自動取 Excel）

### 5.1 不在內聯網

瀏覽器先探測 `http://10.127.7.200:17789`。失敗則不取檔，提示：

- zh-HK：`未能連接校內手機櫃系統（10.127.7.200）。請用已連接學校網絡的電腦或手機再按更新。已保存的歷史紀錄仍可查閱。`
- en：`Cannot reach the school locker system (10.127.7.200). Use a computer or phone on the school network and tap Update again. Saved history remains available.`

### 5.2 按下「更新」之後（主路徑）

全部在**用戶瀏覽器**進行，無需再開 OpenLog、無需人手導出：

1. 組成日期範圍：首次 `2025-09-01`～今天；其後上次成功開門日（重疊 1 日）～今天。
2. `fetch` 原廠導出 Excel 的 HTTP API（實作時對 SPA 的實際路徑；目標等同頁面「導出 Excel」）。
3. 帶上認證：設定頁保存的 `__tea_session_id_586864` JSON（放進與原廠相同的 header／cookie 欄），並 `credentials: 'include'`（若同一瀏覽器已登入原廠，cookie 會一併送出）。
4. 讀取 `.xlsx` 位元組，POST 到本系統 `/api/import`。
5. 伺服器解析九欄、去重、重算 `student_current`／`locker_current`，更新 `sync_state`。

設定頁的 session **是自動取檔所需要的**（瀏覽器不能讀原廠分頁的 sessionStorage）。失效時提示到設定頁貼新的。

### 5.3 CORS 或 401

- 未登入／session 失效：提示更新 session。
- CORS 無法讀檔：同一按鈕嘗試同源轉發（Docker 須在校網）；再失敗才顯示錯誤。不強迫人手導出，除非你之後要求加後備上傳。

### 5.4 日期與去重

- 首次：`from = 2025-09-01`，`to = 今天（香港）`。
- 其後：`from = last_success_open_date`（重疊 1 日），`to = 今天`。
- 不清舊 log。指紋：`开箱时间` + `用户编号` + `locker_code` + `开箱类型`。

### 5.5 09:45／18:30

沒有人開著本頁時，瀏覽器無法代取。改為有分頁開著且在校網時提示按「更新」。不在伺服器做無人值守爬蟲。

## 6. 畫面（尚未實作，僅規格）

右上：`繁體中文（香港）` / `English`。日期 `yyyy-mm-dd`。

### 6.1 登入

`admin` / `000000`。錯誤不區分帳號或密碼。

### 6.2 設定頁（你要求新增）

已登入才能開。

| 欄位 | 說明 |
|------|------|
| 內聯網網址 | 預設 `http://10.127.7.200:17789` |
| Session Storage | **自動取 Excel 需要。** 貼 `__tea_session_id_586864` 的 JSON 或 UUID |
| 導出 API 路徑 | 實測後填；可留空由程式試常見 `/api/.../export` |
| 首次匯入日起 | 預設 `2025-09-01` |
| 每櫃格數上限 | 預設 `120` |
| 同步說明 | 顯示建議日期範圍；09:45／18:30 為提醒而非伺服器代抓 |

### 6.3 首頁 — 學生

表格：班別、學號、姓名（無則留空不寫「空」）、最後箱門、最後使用日期時間（無則「空置」）。搜尋班別／學號／姓名。每列有「以往記錄」。

只列出 **log 裡出現過的學號**。無名冊、不列從未開門的學生。

### 6.4 首頁 — 箱門

分櫃 **A 櫃 … G 櫃**。每櫃以**密集格線**顯示 `001`–`120`（各櫃實際格數不同，上限 120；多出來的格若無紀錄即「空置」）。

每格：

- 格號 `003`（三位）
- 學生姓名（無則不寫該行）
- 最後使用時間（`yyyy-mm-dd HH:mm:ss`）
- 按鈕：以往記錄

該格完全無事件：**空置**（不顯示姓名與時間）。可提供「隱藏空置」開關，避免 120 格太長；預設顯示全部以便對實物。

有事件：即使最後一次是取出，仍顯示該學生 + 最後時間。

### 6.5 以往記錄頁

來自學生列或箱門按鈕。表列：开箱时间、用户名、用户编号、所属部门、箱门、开箱类型、验证方式、管理员、备注。可再篩日期。分頁。

### 6.6 頁首同步列

- 內聯網狀態（本機瀏覽器探測）
- 將使用的日期範圍（只讀顯示）
- 按鈕 **「更新」**：自動由瀏覽器取 Excel 並入庫（進行中顯示載入）
- 最後成功同步時間

不做「請用戶自己導出再上傳」作為主流程。

### 6.7 第一期不做

Google 登入、校外存取、遙距開箱、學生自助、推播、改原廠 `:17789` 系統。

## 7. 資料庫

### 7.1 `users`

`login_name=admin`，`password_hash`，`email` 可空（第二期），`role=admin`。

### 7.2 `app_settings`（單列）

`intranet_base_url`，`session_storage_key` 預設 `__tea_session_id_586864`，`session_payload`（敏感 JSON），`export_api_path`（可空），`first_import_date` 預設 `2025-09-01`，`doors_per_cabinet` 預設 `120`，`updated_at`。

### 7.3 `sync_state`（單列）

`last_attempt_at`，`last_success_at`，`last_success_open_date`，`last_error`，`last_row_count`。

### 7.4 `open_events`

`opened_at`，`student_name`，`student_no`，`class_code`，`cabinet`，`door_no`，`locker_code`，`open_type`，`verify_method`，`admin_name`，`remark`，`source`（`browser_upload` / `browser_fetch`），`row_fingerprint` unique，`raw_json`。

### 7.5 `student_current` / `locker_current`

由事件重算。箱門總覽產生 A–G × `001`…`120`；無對應事件則畫面「空置」。超過 120 的格號若出現在 Excel，仍入 `open_events` 並顯示（不丟資料）。

## 8. 安全

- 本系統密碼 bcrypt；內聯網 session JSON／token 只存設定表，不進版控、不寫 info log。對話裡的 UUID **不會**寫進倉庫。
- Cookie session：`httpOnly`、`sameSite=lax`；校內 HTTP 不強制 `secure`。
- 同步與改設定必須已登入。
- 上傳限 `.xlsx`／`.xls`、20 MB。
- 不提供刪改單筆開門事實；不去清舊 log。
- PostgreSQL 不映射到校外。防火牆僅校內開 `:3000`。
